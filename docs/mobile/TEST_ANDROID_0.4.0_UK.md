# KNABA Test 0.4.0 — інструкція для Android

Це окрема тестова Android-програма для перевірки нативного інтерфейсу KNABA DE. Вона містить явно позначений деморежим і вхід до сумісної ERP. Деморежим не підтверджує готовність живої ERP, сайту, iOS або всього проєкту.

## Встановлення та перший запуск

1. Завантажте `KNABA-0.4.0-test.apk` на телефон з Android 12 або новішим.
2. Відкрийте файл. Якщо Android запитає, дозвольте встановлення саме для програми, якою відкриваєте APK. Після встановлення цей дозвіл можна вимкнути.
3. Запустіть **KNABA Test**. Вона має окремий ідентифікатор `de.knaba.mobile.test` і не замінює стару `de.knaba.mobile`.
4. На першому екрані натисніть **Sprache → Українська**. Доступні DE, EN, PL, LT, RU, UK; початкова мова — німецька.
5. Натисніть **Тест без сервера** / **Ohne Server testen**. Логін, пароль і сервер для цього не потрібні.

APK має тестовий debug-підпис. Це файл для оцінювання, не випуск Google Play і не підписаний ключем власника production-реліз.

## Вхід до тестової ERP

Для живої перевірки використовуйте окремий погоджений тестовий сервер та тестові облікові записи. На початковому екрані можна вказати адресу сумісного HTTPS ERP-сервера, email, пароль та за потреби шестизначний код MFA. Адреса має бути origin без `/konto/` або іншого шляху. Обліковий запис сайту KNABA та обліковий запис ERP поки не об’єднані. Права, доступні записи та команди визначає ERP-сервер.

Для цієї передачі робочий ERP origin і тестовий обліковий запис не підтверджені. Read-only запити з середовища перевірки до `knaba.de` та `testing.knaba.de` отримали HTTP 403 / Cloudflare 1010. Це не доказ непрацездатності сайту на вашому телефоні, але живий вхід і реальні операції тут не перевірені.

У разі невідомого результату операції програма зберігає початковий запит і ключ повтору в пам’яті. Скористайтеся дією відновлення, щоб повторити той самий запит. Після примусового завершення програми або виходу спочатку звірте результат на сервері перед повторним створенням операції. Довготривале відновлення невідомих ERP-команд після загибелі процесу залишається відкритою вимогою.

## Межі перевірки

Точні результати збірки, тестів, незалежного review, SHA-256 APK та сертифіката наведені в `evidence/android-test-20261107/verification.json`. Автоматизовані Android UI-тести використовують Robolectric та явно синтетичні дані. Вони не замінюють фізичне встановлення, GPS/батарейні тести, перевірку live ERP і приймання замовником.

Наявні повні вимоги KNABA збережені в канонічних roadmap/backlog. Ця APK не закриває інтеграцію облікових записів сайту/ERP, весь бізнес-процес, iOS, реальних провайдерів або production-реліз. Наступний зовнішній крок — перевірка на телефоні та на наданій тестовій ERP з окремими тестовими користувачами.
