# ADR 0001 — modular monolith and durable command engine
Accepted 2026-10-05. Node 24 LTS, strict TypeScript, NestJS HTTP, React 19/Vite 7 PWA, PostgreSQL 17.6. A separate worker leases the transactional PostgreSQL outbox using SKIP LOCKED; Redis is unnecessary for current throughput and is not an alternative source of truth. S3 adapter stores private media. Native Kotlin and Swift components use /api/v1.
Company-scoped typed aggregates persist in a single JSONB aggregate table with stable kind/id, version and immutable revision/audit records. Boundaries and references are validated by domain commands. This avoids duplicate stores for chat/web. Company advisory transaction lock serializes scarce-resource changes; expected_version prevents stale UI changes. This is intentionally coarse locking for one-company first release; can partition locks after measuring load. PostgreSQL constraints enforce idempotency and stable IDs; immutable history protects issued documents.
All commands carry actor, permission, schema, scope, expected_version and idempotency_key. Domain agents own operations.ts, commerce.ts, resources.ts, communications.ts independently. Root owns core.ts, database, identity and route authorization. External integrations are disabled unless configured; real legal gates cannot be replaced by synthetic fixtures.
