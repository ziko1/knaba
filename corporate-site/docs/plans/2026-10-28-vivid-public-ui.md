## Рішення

- Додатковий `public-vivid.css` застосовується через явний атрибут лише до публічних сторінок. Приватні інтерфейси не отримують публічну тему.
- Бірюзовий, лаймовий, персиковий і бузковий акценти, світла підкладка hero, контрастна перша картка каруселі та узгоджені картки каталогу. Поточні зображення й тексти збережені.
- Чіткі hover/focus/pressed стани, видимий поточний пункт меню, достатні зони натискання. Мобільне меню прокручується в межах короткого екрана.
- Карусель лишається ручною. Мобільні індикатори мають зону 26×44 px, стрілки 44×44 px; лічильник доступний візуально.
- `public-motion.ts`: одноразові короткі анімації лише нижче першого екрана; `IntersectionObserver` + Web Animations API. Без прихованого SSR-вмісту, постійних scroll listeners, сторонніх анімаційних пакетів або анімації hero/LCP.
- Reduced motion, зміна видимості вкладки, keyboard focus і переходи Astro припиняють активні ефекти. Повторне підключення не накопичує observers/listeners.
- Швидкодія перевіряється порівнянням реальних артефактів із baseline. Чинні ліміти CSS/JS збережені; результати наведені в окремому QA receipt.
- Історичні CSS-правила лишаються в джерелах. Наявний LightningCSS не включає в артефакт лише обмежений список невикористаних старих класів, перевірений по runtime-джерелах; невідомий динамічний клас або неповний scan вимикає оптимізацію. Окремий HTML guard відхиляє збірку, якщо вилучений клас фактично присутній у сторінці.

## Межі та rollback

Це доповнення до публічного дизайну. Схема даних, авторизація, API, провайдери, залежності, DNS і платні послуги не змінюються. Злиття в `main` і customer production не входять у цей запит. Попередній staging release зберігається; source rollback — revert ізольованого feature commit. Для серверного rollout діють наявні source lease, backup/restore, storage і release gates.

На початку локального QA браузерні executable Chromium/WebKit/Firefox були відсутні: штатний `test:logo:browser` повернув `BLOCKED / NO_USABLE_BROWSER`. Це не помилка сайту й не PASS. Хмарний браузер відкрив чинний `https://kneba.vsp.rest/`, але не має доступу до локального loopback preview. Остаточний результат browser QA фіксується в receipt.
