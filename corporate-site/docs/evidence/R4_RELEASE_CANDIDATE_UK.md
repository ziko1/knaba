## Реалізовано
1. **Мінімізація PII**: у клієнтській відповіді API `assignedWorkerId=null`; користувачам ролей admin/owner призначення доступні, worker отримує лише власні роботи.
2. **Посторінкові списки**: `GET /api/portal/requests?after=...` та `GET /api/portal/profiles?after=...` повертають до 50 записів і `nextAfter`. Курсор — дата й ID позиції сортування, не авторизація; усі запити повторно перевіряють роль на сервері, параметри bind, профілі адміністратору обмежено затвердженими працівниками без email.
3. **Кабінети без перезавантаження**: завантаження давніших заявок і реєстрацій у наявному SolidJS UI; DE/EN/UK назви кнопок; при зміні авторизації або оновленні кеш очищується. Прострочена мережева відповідь відхиляється після зміни ідентичності.
4. **Узгоджені контракти й документація**: зміни в PortalPage, README, ROADMAP, PROJECT_MEMORY; жодних міграцій БД, дубльованих сайтів чи нової системи авторизації.
