# Узгодження домену клієнтського редактора KNABA

## Результат і межі

Виправлено джерельний код та перевірено нову офіційну збірку. Це кандидат для інтеграції у чинне перенесення на акаунт власника; публічний DNS, тунелі, поточна production/testing версія та пошта цим виправленням не змінювалися.

Перевірений код: `d57c342224c831307c36dec6da9a83463e31f10f`, база `0cf80e3010d1a52c5147456bce3bf6db5c7ac06d`.
Клієнтська збірка: `11c01f5db33356a4c7ec7ce196a21743e9ad4f3f270bc8cd864e5d54bf9d04ac`.

## Причина і зміна

У попередньому браузерному модулі приватний `KNABA_RELEASE_MODE` перетворювався на відсутню властивість. Редактор відхиляв абсолютний URL `https://knaba.de/kontakt/`, але приймав старий preview URL. Звичайні публічні HTTP-маршрути цим дефектом не доведені несправними.

У `astro.config.mjs` один Boolean визначає адресу сайту та один явно дозволений Vite build constant. Інші environment values не експортуються. Чинна сувора перевірка origin, відносних посилань і URL із credentials збережена; нових залежностей немає.

## Обмеження і наступний крок

Повний runtime package ще не staged/activated. Реальний браузерний editor journey, owner/provider acceptance і зовнішній smoke після cutover не виконувалися цим workstream. Вебпоказники на реальних пристроях не вимірювалися.

Єдиний відповідальний за customer deployment має включити цей перевірений source/client candidate у чинний release flow, зберегти наявні дані та потрібні дистрибутиви, підтвердити офіційний production origin, підключити вже наявний тунель власника, а потім перемкнути лише вебзаписи DNS і перевірити публічні маршрути. Поштові записи та приватний VSP Access зберігаються.

Первинний тестовий harness використовував Node ESM import, який допускав вплив process.env/module cache; його результат виключено з приймання й збережено лише як діагностику. Виправлений VM harness відтворив справжній дефект до source patch. Чинні журнали та SHA-256 наведені в checks.json; generated-asset-verification.json розрізняє правильний official і старий staging report.
