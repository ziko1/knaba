Опублікований kneba.vsp.rest (стара release-ціль 21a56934f3c3266d31285bb89e0a4ca0c0f755a4) повторює посилання на контакти/каталог у різних зонах. ## Виправлення

1. Порядок: hero → основні послуги (шість карток) → додаткові роботи → процес → компанія → партнери → відгуки → FAQ → фінальна заявка. Спільні компоненти повторно використані.
2. Зайвий CTA під сіткою видалено, одна secondary-кнопка каталогу в hero, окремий запит як основна дія. Для додаткових робіт чотири точні локалізовані підписи; посилання на каталог #zusatzarbeiten.
3. Фокус клавіатури, контраст, мобільне вертикальне вирівнювання двох кнопок, доступні aria-labelledby для змістових блоків.
4. Регресії додані до чинних contact-ui-dedup, marketing-contrast і verify-build; marketing-contrast включено до стандартного npm test без створення дублюючої QA-системи.
