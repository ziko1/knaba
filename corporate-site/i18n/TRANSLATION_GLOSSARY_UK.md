# KNABA — юридично обережний глосарій перекладу

Писати бренд KNABA/KnaBa без перекладу. Не змінювати затверджені геометрію, акцент логотипа й контраст. Слоган Unser Ziel ist Ihre Wertschöpfung перекладати після перегляду носієм мови без додавання обіцянок.

- Baureinigung — будівельний клінінг, не просто офісне прибирання.
- Baugrobreinigung / Bauzwischenreinigung / Baufeinreinigung / Bauendreinigung — грубе / проміжне / тонке / завершальне прибирання.
- Baustellenberäumung — розчищення майданчика.
- Bauhilfe / Bauhelfer — лише погоджені допоміжні завдання; не твердження про ліцензовані спеціальні роботи.
- Kernbohrungen / Durchbrüche — лише запит після технічної перевірки, кваліфікованого виконавця, дозволів та окремого договору.
- Berlin und Brandenburg — зберігати географію, не вигадувати філій.
- Angebot anfragen — запит пропозиції, не підтверджений контракт, ціна чи бронювання.
- Impressum / Datenschutz / DSGVO — юридичну сутність затверджує фахівець; машинний переклад без юридичної перевірки не публікувати.

Не вигадувати сертифікатів, партнерів, відгуків, гарантій, контактів, послуг чи рівня дозволів. Власницька оцінка контенту, зокрема українською й RTL-мовами, має бути окремою.
