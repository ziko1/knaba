# KNABA DE iOS companion

SwiftUI / Core Location, iOS 16+, Xcode 16+, Swift 5 language mode. `Sources/` is an executable native application, with Keychain device bearer/encryption keys, CryptoKit AES-GCM atomic offline persistence, strict HTTPS origin and no redirects, exact event-ID receipts, explicit tracking activation and bounded renewable server leases. Background permission is a separate user action, and the app visibly reports tracking. GPS stops locally before enqueueing a private break or END. Missing GPS remains UNKNOWN; manual time commands work without GPS.

On a company-authorized macOS builder with XcodeGen 2.43.0, run `bash scripts/build.sh`. Optional `KNABA_IOS_TEST_DESTINATION='platform=iOS Simulator,name=iPhone 16'` runs native unit vectors and preserves `.xcresult`. The unsigned simulator application appears at `build/Build/Products/Debug-iphonesimulator/KNABADE.app`. XcodeGen generates the project from checked-in `project.yml`; no generated signing identity is supplied. Production needs KNABA's Apple team, provisioning profiles and review of the checked-in privacy declarations. Do not represent simulator output as a signed phone build.

Exact historical source `3c85adc228ddd5c6078e7bbc05e4d5570625c978` compiled as an unsigned simulator app and passed 4 classifier/lease XCTest cases in native run `37529346218`; see `docs/evidence/native-run-37529346218-summary.json`. The subsequent six-language/card/authorization-fence changes below require their own hosted compile and XCTest run. This Linux workspace has no Swift/Xcode. Local dictionary/placeholder/plist checks are static evidence, not Swift compilation. Physical background/battery/OS/offline acceptance and production signing remain **NOT_RUN / BLOCKED_EXTERNAL**. The OS may stop or delay delivery after force-stop, reboot, denied permissions or power constraints; the app never requests hidden restart.

The interface has an explicit DE/UK/RU/PL/LT/EN selector, with a supported device-language fallback and German only when no preferred device language is supported. It covers all current UI, privacy, validation, tracker states and friendly errors. The selection stores only a locale preference, no account or location data. Six localized `InfoPlist.strings` resources explain OS permissions; iOS chooses its own permission-dialog language from its app/device settings.

“My shift” decodes only optional `shiftSummary` from the authenticated own-device session: IDs/site labels, activity/start/snapshot times and distinct site/travel/break/pending/service/wait counters. It does not grant GPS permission or establish payability/presence. Absent, future, wrong-shift/site, negative or impossible projections do not become a zero-time claim. Counters freeze at their recorded snapshot when a local command/reconciliation is pending, review is required or the snapshot is over 5 minutes old. A bounded display increment for a known current activity is explicitly provisional. Access denial/sign-out clears displayed summary; authorization epochs reject late enrollment/receipt writes and late GPS-enable responses after a privacy stop. Eleven new XCTest cases cover dictionary coverage, locale selection, error translation, projection arithmetic/bounds/freeze/identity and revoked late writes/old-lease privacy stop; their execution is pending the next native CI run.

Bedienung: Wählen Sie die Sprache oder die Gerätesprache. Verknüpfen Sie das Gerät mit dem einmaligen Code aus Ihrem Webkonto. Synchronisieren Sie, um die bestätigte Schichtübersicht zu laden. START beginnt eine manuelle Schicht, aktiviert aber kein GPS. Eine private Pause oder END stoppt GPS sofort lokal; gespeicherte Aktionen sind bis zur Serverbestätigung unbestätigt. Aktivieren Sie Standort nur ausdrücklich und mit gültiger Serverfreigabe. Fehlende oder veraltete Position bedeutet unbekannt, nicht Abwesenheit. Bei Abmeldung werden lokale Kontodaten gelöscht; eine fehlgeschlagene Löschung wird als Fehler angezeigt.
