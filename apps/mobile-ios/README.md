# KNABA DE iOS companion

SwiftUI / Core Location, iOS 16+, Xcode 16+, Swift 5.9 language mode. `Sources/` is an executable native application, with Keychain device bearer/encryption keys, CryptoKit AES-GCM atomic offline persistence, strict HTTPS origin and no redirects, exact event-ID receipts, explicit tracking activation and bounded renewable server leases. Background permission is a separate user action, and the app visibly reports tracking. GPS stops locally before enqueueing a private break or END. Missing GPS remains UNKNOWN; manual time commands work without GPS.

On a company-authorized macOS builder with XcodeGen 2.43.0, run `bash scripts/build.sh`. Optional `KNABA_IOS_TEST_DESTINATION='platform=iOS Simulator,name=iPhone 16'` runs native unit vectors and preserves `.xcresult`. The unsigned simulator application appears at `build/Build/Products/Debug-iphonesimulator/KNABADE.app`. XcodeGen generates the project from checked-in `project.yml`; no generated signing identity is supplied. Production needs KNABA's Apple team, provisioning profiles and review of the checked-in privacy declarations. Do not represent simulator output as a signed phone build.

This Linux execution environment has no Swift/Xcode/macOS signing capability. iOS compile/test/install and physical background/battery/permissions checks are **NOT_RUN / BLOCKED_EXTERNAL** until exact logs, `.xcresult`, app hash and approved device evidence are attached. Source completion does not prove reliable Core Location behavior on real iPhones. The OS may stop or delay delivery after force-stop, reboot, denied permissions or power constraints; the app never requests hidden restart.
